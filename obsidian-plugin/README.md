# Referee for Obsidian

Checks the note you're writing against the reading the Referee browser extension has captured, and tells the extension you're writing so automatic mode captures what you read.

## Install

1. Start the Referee server (see the main README).
2. Copy this folder into your vault as `.obsidian/plugins/referee/`.
3. In Obsidian, go to Settings → Community plugins, turn on community plugins if needed, and enable Referee.
4. Click the ✓ icon in the left ribbon to open the panel.

Settings let you change the server address and choose a project.
